# Data Sources Catalog

The Atlas integrates 90+ indicators from 16 institutional API connectors, spanning macroeconomics, poverty, governance, health, education, trade, and climate.

| Connector                        | Provider                              | Indicator families                                           |
| -------------------------------- | ------------------------------------- | ------------------------------------------------------------ |
| World Bank Open Data             | The World Bank Group                  | GDP, GNI, poverty headcount, inflation, trade balance        |
| IMF World Economic Outlook       | International Monetary Fund           | Fiscal balance, public debt, GDP forecasts                   |
| WHO Global Health Observatory    | World Health Organization             | Life expectancy, maternal mortality, immunization coverage   |
| UNESCO Institute for Statistics  | UNESCO                                | Literacy rates, school enrollment, education expenditure     |
| UN Comtrade                      | United Nations Statistics Division    | Bilateral trade flows, export/import composition             |
| Freedom House                    | Freedom House                         | Political rights & civil liberties indices                   |
| UNDP Human Development Reports   | UN Development Programme              | Human Development Index (HDI), inequality-adjusted HDI       |
| UNHCR Refugee Data Finder        | UN Refugee Agency                     | Refugee & IDP populations                                    |
| ILOSTAT                          | International Labour Organization     | Labor force participation, youth unemployment                |
| FAO STAT                         | Food and Agriculture Organization     | Agricultural output, food security indices                   |
| ITU                              | International Telecommunication Union | Internet penetration, mobile subscriptions                   |
| World Bank Governance Indicators | The World Bank Group                  | Rule of law, control of corruption, government effectiveness |
| Global Peace Index               | Institute for Economics & Peace       | Peace & conflict scoring                                     |
| UNESCO World Heritage Centre     | UNESCO                                | World Heritage Site inventories                              |
| Slave Voyages Database           | Slave Voyages research consortium     | Historical transatlantic voyage records                      |
| Natural Earth / Own SVG geometry | Internal                              | Coastlines, borders, and cartographic boundaries             |

Indicators refresh on each connector's own publication cadence — most institutional sources listed here update annually; some (trade, health surveillance) update quarterly. See Provenance & Data Quality in the User Guide for how staleness and estimation are flagged in the UI.
