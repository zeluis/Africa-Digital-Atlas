# Thematic Pillars

Indicators across the Atlas are organized into consistent development pillars, used throughout the comparative analytics radar charts and country dossiers:

* **Economic Output**
* **Governance & Rule of Law**
* **Healthcare Access**
* **Digital Infrastructure**
* **Education Equity**
* **Climate Resilience**

Each pillar aggregates multiple underlying indicators (see [Data & Methodology](https://fpizeluis.gitbook.io/fpizeluis-docs/api-reference/) for the full catalog) into a single normalized score for cross-country comparison.
