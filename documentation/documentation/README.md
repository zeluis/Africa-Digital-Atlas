# User Guide

This guide walks through each module of the Africa Digital Atlas, the pan-African data and cartography platform. Open the [live app](https://zeluis.github.io/Africa-Digital-Atlas/) alongside these pages to follow along.

## Features

* [Vector Cartography Map](vector-cartography-map.md) — the interactive continental map and choropleth engine
* [Country Dossiers](country-dossiers.md) — in-depth national profiles
* [Comparative Analytics](comparative-analytics.md) — correlation scatter plots and radar comparisons
* [Regional Economic Blocs](regional-economic-blocs.md) — AU, ECOWAS, EAC, SADC, and other RECs
* [Slave Voyages 3D Globe](slave-voyages-3d-globe.md) — the historical maritime flow visualizer
* [Thematic Pillars](thematic-pillars.md) — development pillars used across the platform
* [Provenance & Data Quality](provenance-and-data-quality.md) — integrity audits and citation tools
* [Languages](languages.md) — the multilingual (i18n) engine
