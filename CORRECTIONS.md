# Errata & Methodological Corrections Log (`CORRECTIONS.md`)

This file records substantive corrections to datasets, observation status flags, source attributions, and documentation across the **Africa Data Atlas & Cartographic Observatory**.

To report an error or suggest a correction, open an issue using the [Data or Citation Correction template](.github/ISSUE_TEMPLATE/data-correction.md).

---

## 2026-10-04 — Release 2026.1 Audit & Harmonization

### CORR-2026-01: Historical Indicator Back-Fill Status Flags (`2015`, `2020`, `2022`)
- **Scope**: `src/data/atlas-observations-seed.ts`, `src/data/atlas-raw-data.ts`, `src/utils/exportUtils.ts`
- **Issue**: Prior historical time-series points (`2015`, `2020`, `2022`) for certain indicators were generated by applying deterministic scaling factors to `2024` baseline figures, but were tagged `status: 'observed'`.
- **Correction**: Added `'derived'` to `ObservationStatus` (`observed | estimated | forecast | derived`). Tagged all scaled historical back-fills as `status: 'derived'` with explicit `notes` documenting the scaling formula, and updated CSV/JSON exports to include each observation's status flag and notes.
- **Guardrail**: Added `codePatterns` rule in `research/rules.json` blocking unflagged scaling expressions.

### CORR-2026-02: SlaveVoyages Documented Years (`1514–1866`) vs. Demographic Estimates (`1501–1866`)
- **Scope**: `src/data/slaveVoyagesData.ts`, `src/views/SlaveTradeView.tsx`, `docs/guide/slave-voyages.md`, `README.md`
- **Issue**: Some UI headers and documentation conflated the documented voyage span (`1514–1866`, `36,108` documented voyages and `18` curated voyage dossiers in the *SlaveVoyages* 2024.1 release) with the broader `1501–1866` continental demographic estimate window (or cited `1501–1867`).
- **Correction**: Standardized all documented voyage spans to `1514–1866` (`36,108` voyages; `18` curated dossiers) and explicitly separated the three layers: **Observed (`1514–1866`)**, **Imputed (`1514–1866`)**, and **Estimated (`1501–1866`)**.
- **Guardrail**: Added `1501–1867` error rule in `research/rules.json`.

### CORR-2026-03: Ethnic Group Catalog Source & Population-Genetics Clustering Attribution
- **Scope**: `src/components/ethnicTree/AfricaliaExplorer.tsx`, `src/components/MethodologyAuditModal.tsx`, `docs/data/citations-licensing.md`, `CITATION.cff`
- **Issue**: Citations to Bird et al. (2023) and Tishkoff et al. (2009) needed clearer separation from the source of the 310 ethnic group entries.
- **Correction**: Clarified across the UI and documentation that the **310 contemporary ethnic groups** come from Wikipedia's *List of contemporary ethnic groups of Africa* (retrieved `2026-01`), while **Bird et al. (2023)** (`10.1126/sciadv.abq2616`) and **Tishkoff et al. (2009)** (`10.1126/science.1172257`) are cited strictly for their **clustering framework** (how genetic clusters relate to ethnicity, language, and geography), without reproducing their samples or genetic data.

### CORR-2026-04: Standardization to 8 Thematic Pillars
- **Scope**: `src/views/ThematicPillarsView.tsx`, `docs/guide/thematic-pillars.md`, `documentation/documentation/thematic-pillars.md`, `README.md`
- **Issue**: Several documentation pages referred to "6 Thematic Pillars" while the application implements **8 thematic pillars**.
- **Correction**: Updated all documentation and UI summaries to list all 8 thematic pillars defined in `research/facts.json`.
- **Guardrail**: Added `6 Thematic Pillar` error rule in `research/rules.json`.

### CORR-2026-05: Browser Web Crypto API SHA-256 Dataset Verification
- **Scope**: `src/data/methodologyDossierData.ts`, `src/components/MethodologyAuditModal.tsx`, `research/checksums.json`, `research/hashes.json`
- **Issue**: Dataset integrity badges previously displayed static "Verified" labels without computing hashes in the browser.
- **Correction**: Published real build-time SHA-256 checksums for all 8 foundational datasets and wired the **Verify** button in `MethodologyAuditModal.tsx` to compute live SHA-256 digests in the browser using `crypto.subtle.digest('SHA-256', ...)`.
- **Guardrail**: Added `zero manual tampering` and `Universal SHA-256 Checksum Verified` error rules in `research/rules.json`.

### CORR-2026-06: Universal Figshare DOI, Removal of ISSN Placeholders, and Dual Licensing (`LICENSE-CODE` & `LICENSE-ASSETS`)
- **Scope**: `CITATION.cff`, `LICENSE-CODE`, `LICENSE-ASSETS`, `research/facts.json`, `research/sources.json`, and all citation/licensing views
- **Issue**: Working paper templates contained placeholder `ISSN` strings, and creative assets vs. source code licensing needed explicit file separation at the repository root.
- **Correction**: Removed all `ISSN` references across the codebase, standardized on the universal Figshare DOI (`https://doi.org/10.6084/m9.figshare.34065711`) and ORCID (`0000-0001-9421-6555`), and established separate root license files: `LICENSE-CODE` (MIT License for source code) and `LICENSE-ASSETS` (CC BY 4.0 for all SVG maps, the Ethnic Tree Visualization and SVG, and graphics/visualizations authored by **ZéLuis F. Correia**).

### CORR-2026-07: Editorial Voice Ratchet to Zero Warnings & Institutional Logo Reference Links
- **Scope**: `src/`, `docs/`, `README.md`, `public/manifest.json`, `src/components/OrganizationLogo.tsx`, `research/lint-baseline.json`
- **Issue**: 64 warning instances of discouraged promotional terms (`authoritative`, `unprecedented`, `forensic`) remained across UI and docs, and 9 `wikimediaUrl` reference links in `OrganizationLogo.tsx` pointed to 404 Wikimedia File pages.
- **Correction**: Replaced all discouraged promotional terms with plain, descriptive alternatives (`curated`, `documented`, `canonical`, `osteological`, `institutional`) per `VOICE_AND_TONE.md`, ratcheted `research/lint-baseline.json` down to `0` warnings across all rules, and updated `OrganizationLogo.tsx` reference links to official institutional URLs.
