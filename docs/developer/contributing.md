# Contributing

Contributions are welcome. To propose a change:

1. Fork the repository and create a feature branch.
2. Make your change, following the existing code style and structure.
3. Open a pull request against `main` with a clear description of what changed and why.

## Good areas to contribute

- Adding or refreshing indicator connectors
- Improving accessibility of the map and dossier views
- Adding new language translations to the i18n engine
- Expanding test coverage
- Improving or extending these docs (see `docs/` in the repo)

For larger proposed changes, opening an issue first to discuss the approach is appreciated.
